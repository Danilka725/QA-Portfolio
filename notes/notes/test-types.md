# Виды тестирования

## По объекту тестирования:

### Функциональное
Проверка функциональных требований:
- Работает ли функция?
- Соответствует ли спецификации?
- Правильные ли результаты?

### Нефункциональное
Проверка нефункциональных требований:
- Производительность
- Надёжность
- Удобство использования
- Безопасность

## По уровню доступа:

### White Box (белый ящик)
Тестирование с доступом к коду

### Black Box (чёрный ящик)
Тестирование без доступа к коду

### Gray Box (серый ящик)
Частичный доступ к коду

## По степени автоматизации:

### Ручное
Тестировщик выполняет тесты вручную

### Автоматизированное
Скрипты выполняют тесты

## По целям:

### Smoke (дымовое)
Быстрая проверка: работает ли вообще?

### Sanity ( sanity check)
Поверхностная проверка после изменений

### Regression (регрессионное)
Проверка, что старое не сломалось

### Acceptance (приёмочное)
Проверка заказчиком перед приёмкой

### Integration (интеграционное)
Проверка взаимодействия модулей

### System (системное)
Проверка всей системы целиком
