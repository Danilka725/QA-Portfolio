# Примеры тест-кейсов

## TC-001: Проверка поиска товара на Ozon

**Preconditions:**
- Открыт сайт ozon.ru
- Есть подключение к интернету

**Steps:**
1. Найти строку поиска в шапке сайта
2. Ввести текст "наушники"
3. Нажать клавишу Enter или кнопку поиска

**Expected Result:**
- Отобразится страница с результатами поиска
- В результатах присутствуют товары со словом "наушники"
- Работают фильтры (цена, бренд, рейтинг)
- Количество результатов > 0

**Actual Result:** ✅ Прошло

**Severity:** Normal  
**Priority:** Medium

## TC-002: Добавление товара в корзину

**Preconditions:**
- Открыта страница товара
- Товар есть в наличии

**Steps:**
1. Нажать кнопку "В корзину"
2. Дождаться появления уведомления
3. Перейти в корзину

**Expected Result:**
- Товар отображается в корзине
- Количество товаров = 1
- Сумма заказа = цене товара

**Actual Result:** ✅ Прошло

**Severity:** Normal  
**Priority:** High

## TC-004: Проверка валидации формы регистрации

**Preconditions:**
- Открыта форма регистрации

**Steps:**
1. Ввести email: invalid-email (без @)
2. Ввести пароль: 123 (меньше 6 символов)
3. Нажать кнопку "Зарегистрироваться"

**Expected Result:**
- Отображается ошибка "Некорректный email"
- Отображается ошибка "Пароль слишком короткий"
- Регистрация не происходит

**Actual Result:** ⬜ Не тестировалось

**Severity:** Major  
**Priority:** High
