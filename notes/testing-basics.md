# Основы тестирования ПО

## Что такое тестирование?
Процесс проверки соответствия ПО требованиям и выявления ошибок.

## Основные понятия:

### Ошибка (Error)
Неправильное действие разработчика при написании кода.

### Дефект (Defect/Bug)
Ошибка в коде, которая может привести к неправильной работе.

### Сбой (Failure)
Неправильная работа программы при выполнении.

## Жизненный цикл бага:

1. **New** — новый баг найден
2. **Assigned** — назначен на разработчика
3. **Open** — в работе
4. **Fixed** — исправлен
5. **Retest** — проверка тестировщиком
6. **Verified** — проверен, закрыт
7. **Closed** — закрыт

ИЛИ:
- **Rejected** — отклонён (не баг)
- **Deferred** — отложен на потом
- **Cannot Reproduce** — не воспроизводится

## Роль QA в команде:

- Поиск дефектов до релиза
- Профилактика ошибок (тестирование требований)
- Контроль качества продукта
- Документирование находок
